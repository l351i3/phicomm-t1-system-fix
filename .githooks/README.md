# .githooks — 内容门禁

本目录是仓库自带的内容门禁：**任何姿势的提交/推送都会先过一遍受保护模式扫描**，
命中即拦截（fail-closed）。

- `pre-commit`：扫描本次暂存的内容；
- `pre-push`：推送前全量扫描跟踪文件；
- `leak_scan.py`：扫描器本体；
- `patterns.sha256`：受保护模式的 sha256 前 16 位摘要。

## 为什么规则是哈希

规则清单本身包含本仓库**不应出现**的词。若以明文存放，规则文件反而会成为泄露源。
因此这里只存哈希：扫描器把文本归一化（小写、非字母数字折叠为空格）后按长度窗口哈希比对，
命中时报出行号位置与哈希前缀，原文不落盘、不回显。

## 启用

```sh
git config core.hooksPath .githooks
```

（克隆本仓库后执行一次即可；`leak_scan.py` 需要 python3。）

## 命中之后

拦截只是提示"内容里出现了受保护模式"。请人工核对命中位置：
若是误报，调整文案后重新提交；若确属受保护内容，请勿提交——这类内容不应进入本仓库。
